# Whatssap Business Pro

Aplikasyon endepandan ki konbine:
- Chat prive
- Status 24 èdtan
- Status Boost / Sponsored
- Marketplace
- Clips / videyo kout
- Business profile + quick replies
- Wallet multi-deviz
- Depo / retrè / transfè / echanj
- Boost Ads Wallet HTG / USD
- MonCash / NatCash pou demann depo Boost
- Envestisman
- Kòmand ak suivi vant
- Statistik
- Notifikasyon
- Admin dashboard
- Istorik tranzaksyon ak operasyon manyèl admin
- Moderasyon kontni rapòte/pataje

## Endepandans
Repo sa a PA itilize done oswa Firebase Mystro-Shop oubyen MY-Investissements.
Li dwe genyen pwòp Firebase project li.

## Status
- Status nòmal: vizib sèlman pou pwopriyetè a ak kontak li.
- Status ekspire apre 24 èdtan.
- Status Boost: apre admin valide kanpay la, li antre nan Sponsored Status.
- Feed Sponsored la filtre odyans lan dapre mòd automatic/custom, peyi ak laj.
- Si admin mete Boost la an poz, Status la sispann Sponsored.
- Lè Status la ekspire, li pa parèt ankò.

## Boost
Itilizatè a ka:
- chwazi pwodwi, clip oswa status
- chwazi objektif: messages / sales / reach / profile
- chwazi odyans automatic oswa custom
- mete bidjè pa jou
- chwazi HTG oswa USD
- chwazi kantite jou
- depoze nan Ad Wallet ak MonCash oswa NatCash

Depo MonCash/NatCash aktyèl la sèvi ak referans/prèv + validasyon admin.
Pou débit/peman otomatik reyèl, konekte API merchant ofisyèl founisè a nan yon backend sekirize.

## Admin
Admin ka:
- wè kantite itilizatè
- bloke/debloke kont
- wè/modere videyo
- valide/rejte depo, retrè, transfè, payout ak echanj
- valide/rejte kòmand/vant
- valide/rejte envestisman
- valide depo Boost
- aktive/rejte/mete an poz Boost
- kreye nivo envestisman
- fè operasyon manyèl sou wallet itilizatè
- wè istorik walletTransactions
- pale ak itilizatè nan chat sipò
- wè kontni itilizatè rapòte/pataje pou moderasyon

Admin pa gen aksè otomatik nan tout chat prive itilizatè yo.
